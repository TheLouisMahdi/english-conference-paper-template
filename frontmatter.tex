\newcommand{\PaperAbstract}{Batch size can change the apparent performance of a sensor pipeline depending on where latency is measured. This worked example separates ready-request latency, average cost per record, and time from the first sample arrival to batch completion. The example uses an analytical model of a serial link followed by receiver processing. For batches of one and eight, the modeled per-record cost falls from 2.230 ms to 1.705 ms, while the ready-request time rises from 2.230 ms to 13.640 ms. The sample contains equations, a pipeline figure, and documented model inputs in a four-page conference layout.}
